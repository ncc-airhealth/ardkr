# analysis-ready-data

## 목표

대상 데이터를 **Analysis Ready Data**로 만들기 위해, 데이터의 이해와 분석에 필요한 질문을 찾고 근거를 조사해 해소한다.

*Analysis Ready Data: 분석에 필요한 암묵지가 명시지로 전환된 데이터와 메타데이터의 조합.

## 절차

1. `데이터`·`메타데이터`·`적용 가능한 도메인별 질문`을 바탕으로 질문 목록을 만든다.
2. 질문 하나를 골라 조사한다. 먼저 답해야 할 질문이 있으면 그 질문부터 조사한다.
3. 질문에 대한 답·근거·한계를 명시하고, 새 질문은 목록에 추가한다.
4. 현재 질문에서 생긴 후속 질문까지 조사한 뒤 질문 목록으로 돌아간다.
5. 모든 질문에 답하거나 `알 수 없음`·`해당 없음`의 근거를 명시하고, 새 질문이 없으면 종료한다.


## 원칙

* 사실 확인은 파일·데이터·코드·문서·실행 결과로 한다. (사용자의 의도·선택·정책이 필요할 때만 질문한다.)
* 사실·계산한 값·추정한 값을 구분한다.
* 사실에는 출처를, 계산값에는 산출 방법을, 추정값에는 추정 근거를 기록한다.
* 정보가 충돌하면 하나를 임의로 선택하지 않고 충돌·원인·영향을 기록한다.
* 조사해도 답을 알 수 없으면 조사 범위·이유·영향을 기록한다.
* 종료 시 추가·수정한 내용과 근거, 알 수 없는 질문을 보고한다.


## 적용 가능한 도메인별 질문

### 공통

- 데이터가 표현하는 대상
- 생산·수집·가공·제공 주체
- 데이터가 나타내는 시점
- 데이터가 생성·공개·갱신된 시점

### 외부 획득

- 데이터의 출처와 획득 방법
- 메타데이터(문서·코드표 등)의 획득 방법
- 데이터 전체를 빠짐없이 받을 수 있는지 (잘리거나 누락될 위험)
- 같은 출처와 획득 방법으로 다시 받으면 내용이 달라질 수 있는지
- 라이선스 (이용·가공·재배포 정책)
- 생산자·제공자가 밝힌 품질·오차·한계
- 파일 자체의 메타데이터와 출처가 제공한 메타데이터 간 차이점

### 테이블

- 한 행의 의미
- 각 열의 의미
- 열과 열 사이의 제약·종속·계산 관계
- 표가 여러 개일 때 표 사이의 관계
- 빈 값·코드값·범주값
- 기본 키(primary key)

### GIS

- 좌표계 (EPSG 코드 등)
- 범위 (데이터가 다루는 지역)

### GIS - Vector

- 빈 geometry, 유효하지 않은 geometry의 존재여부
- 객체 간 기하적 관계(위상정보)가 유효한지 (인접성, 연결성, 계급성)
- 객체 간 기하적 관계(위상정보)의 의미 해석
- geometry 유형과 multipart 객체에 따른 의미
- 데이터가 표현해야 하는 위상 관계
- Z·M 좌표의 존재여부 (+의미와 단위)
- 기하(위치) 정확도 또는 축척

### GIS - Raster

- 공간해상도
- 밴드(채널)의 의미와 단위 (+nodata, datatype, scale factor, offset)
- 기하보정 품질(기하 정확도)
- 손실압축·리샘플링 등으로 가공 과정에서 값이 변했는지
