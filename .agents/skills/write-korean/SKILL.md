# write-korean

레포에 쓰는 한국어의 문체·품질 규약.
AI 티 나는 번역투를 걷어내고 읽기 쉽게 쓴다.
다 쓴 뒤 이 규칙으로 자기 글을 훑는다.

## 규칙

1. **문체는 형식에 맞춘다.**
   - 항목·규칙 나열(개조식)은 명사형("~함", "~금지")
   - 이어지는 설명은 한다체("~한다")
   - 한 문서 안에서는 일관되게

2. **문장을 짧게 끊는다.**
   - 한 문장에 한 가지만
   - 길고 장황한 문장과 접속 연타("~하며 ~하여")를 피함

3. **번역투를 쓰지 않는다.**
   - 대응하는 한국어가 있는 영어 명사를 그대로 쓰지 않음. caveat→주의사항, placeholder→임시값. 단 STAC·코드·skill 포맷의 고유 개념어(asset, checksum, skill 등)는 예외.
   - 번역투 연결 표현을 피함. "~에 의해"→"~가/이", "~에 있어서"→"~에서", "~를 통해"→"~로/~로써".
