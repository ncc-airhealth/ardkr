# write-python

파이썬 코드를 쓸 때 따르는 규약.
[ponytail](https://github.com/DietrichGebert/ponytail)을 따른다 — 가장 좋은 코드는 쓰지 않은 코드다.

## 코드는 최소로 쓴다

아래 순서로 검토하고, 먼저 걸리는 데서 멈춘다.

1. **필요한가** — 추측성 필요면 쓰지 않음
2. **재사용이 허용된 공용 코드가 있는가** — 있으면 재사용. 작업 전용 skill이 코드 공유를 금지하면 그 규칙을 우선함
3. **표준 라이브러리로 되는가** — 되면 그걸 씀
4. **플랫폼·도구가 기본 제공하는 기능으로 되는가** — 되면 그걸 씀
5. **해당 실행 환경에 선언·고정된 의존성으로 되는가** — 되면 그걸 씀. 몇 줄을 대체하려고 새 의존성을 들이지 않음
6. **한 줄로 되는가** — 되면 한 줄로
7. 그래도 안 되면 최소한의 코드를 씀

코드를 줄이는 것이지 검증·에러 처리를 빼는 게 아니다.

## 문서화

- 공개 API 또는 동작·제약이 명확하지 않은 코드에는 Google 스타일 docstring 사용
- `Args:`, `Returns:`, `Raises:` 같은 표준 섹션명은 영어로, 설명은 한국어로 작성
- 주석은 이유·제약·주의사항을 설명하고 코드 동작을 반복하지 않음
- 상태 변경 등 부수 효과는 docstring 본문에 설명하고 비표준 `Sets:` 섹션은 사용하지 않음
- 주석·docstring의 문체는 `../write-korean/SKILL.md`를 따름
