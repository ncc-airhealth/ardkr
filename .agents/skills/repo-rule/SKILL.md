# repo-rule

이 레포에서 **어떤 상황에서도 변하지 않는 규칙**이다.  
세부 절차가 아니라, 어떤 작업을 하든 항상 적용되는 강한 규칙만 모았다.

## 규칙

1. **에이전트의 git 업데이트 제약**

    다음은 사용자의 명시적 승인 없이 실행·변경하지 않는다.
    - `git add`·`git commit`·`git mv` 등 스테이징·커밋 실행
    - 현재 작업 공간(워크트리) 외부의 파일 변경 또는 명령어 실행

2. **에이전트의 메타데이터 변경 제약**

    다음은 사용자의 명시적 승인 없이 실행·변경하지 않는다.
    - 라이선스 미확인 상태로 `experimental = False` 전환
    - STAC metadata의 `experimental = False` 전환

3. **에이전트의 데이터 수정 제약** 

    다음은 사용자의 명시적 승인 없이 실행·변경하지 않는다.
    - 데이터 저장소(R2) 객체 삭제
    - 데이터 저장소(R2) 객체 업로드가 포함된 스크립트 실행

4. **zero-tacit-knowledge**

    새로 생긴 지식·결정을 대화에만 두고 끝내지 않는다.
    - 데이터 관련 정보는 STAC metadata에 기록
    - 작업 절차는 `.agents/skills/`에 기록
    - 구현 근거는 코드 주석
    - 그 외 순수 지식은 `knowledge/`에 기록
